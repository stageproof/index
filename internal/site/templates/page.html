JSON API

Every document is chart defaults only. A result here is not a verdict on your cluster.

GET {{.IndexPath}}

Catalog JSON

The catalog: schema_version, stageproof_version, notice, and charts. Each chart has id, repo, repo_name, chart, latest, pairs, and blocked.

GET {{.UpgradePattern}}

One upgrade. Fields: schema_version, stageproof_version, scope (chart-defaults-only), notice, reproduce_command, from_sha256, to_sha256, and k8s_results. Each Kubernetes minor holds the Stageproof report for that minor.

Badges

Each indexed upgrade has an SVG at /badge/<repo>/<chart>/<from>/<to>.svg. The image states no blocking finding (defaults), not checked, or the blocking finding. The report is chart defaults only.

/badge/registries.json maps a Helm repository URL and chart name to repo. A pull request requests {{.BadgeURL}}?chart=&from=&registry=&to=. A chart this catalog does not have is HTTP 200 and says not indexed. A chart it has, without that exact pair, says pair not indexed.
