# Security policy

Report a vulnerability through [stageproof/stageproof](https://github.com/stageproof/stageproof/security). Do not open a public issue for a security report.

What the Stageproof check does, and where it sends network requests, is in that repository's [SECURITY.md](https://github.com/stageproof/stageproof/blob/main/SECURITY.md).

This repository publishes chart-default reports. A push to `main` does not deploy the badge worker.
